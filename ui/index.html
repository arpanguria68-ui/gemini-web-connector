System working

      
Your browser is signed in to gemini.google.com. Every request that page makes carries three things: a cookie proving who you are, a session id, and a rotating security token. The proxy replays that handshake from a script, so Google's servers see your login, not an API client.

      
    
        
  1. You sign in at gemini.google.com in Chrome. Normal login, nothing scripted.
    2. 
        
  2. Cookie-sync extension reads cookies, sapisid, xsrf_token, and gemini_bl from the live tab and exports one local file, gemini-auth.json.
    3. 
        
  3. Proxy (gemini_web2api.py, port 8081) turns OpenAI JSON into Gemini's internal format and replays the handshake on each call. xsrf_token, gemini_bl, auth_user live in its config.json; cookies come from the export file.
    4. 
        
  4. This connector (this page, and the MCP server) calls the proxy at /v1/chat/completions with your API key.
    5. 
        
  5. Your tools point their OpenAI base URL here instead of OpenAI.
    6. 
      

      
Chrome login → Cookie extension → gemini-auth.json
                                     ↓
Your tool / this UI → Proxy :8081 (API key) → gemini.google.com

      
The auth header is computed (SAPISIDHASH = sha1 of timestamp, sapisid, and the origin). Model choice is a single integer in the request, taken from Gemini's own frontend. None of it is documented by Google.

    

    

      
Reading the health check

      

        
HealthyPro replies and the model label is gemini-3.1-pro.

        
DegradedPro request answered by Flash: cookie not honored.

        
HTTP 400 / xsrfToken expired.

        
content: nullSession expired or rotated.

        
UnreachableProxy not running. Start it. It has no daemon mode.

      

      
Fix for expiry (about 90 seconds): reopen gemini.google.com/app and refresh, extension → Inspect Session → Export, copy the new xsrf_token and gemini_bl into the proxy's config.json, restart the proxy.

      
Uptime: the laptop must stay awake and the proxy running. Options: disable sleep, use an always-on box, or a cheap VPS.

      
Reaching it off your Wi-Fi: use Tailscale (recommended), Cloudflare Tunnel, or ngrok. Never forward a public port. Keep api_keys non-empty and use a strong key.

    

  


  
  

    

      
Disclaimer

      
This is not an API. It is your browser's login, automated. Every risk below comes from that.

      
Account may be flagged. Google's abuse detection is tuned for one human at a human pace. Scripted or heavy traffic, especially from more than one person, raises the odds. This may also conflict with Google's terms of service. You use it at your own risk.

      
It can break without warning. The proxy chases Google's frontend. One protocol change and it stops working, with no notice and no upgrade path you control.

      
No SLA, no support. If it goes down at 2am, the fix is you re-exporting cookies.

      
The export file is a live login. gemini-auth.json is not an API key, it is an active session. Never commit it, share it, or paste it anywhere (including chats). Treat it like a password. If it leaks, sign out of that session at myaccount.google.com.
